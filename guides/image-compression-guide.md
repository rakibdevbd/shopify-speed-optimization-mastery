# 🖼️ Shopify Image Compression & Formatting Guide
Created by: **Abdullah Al Rakib**

Images are often the heaviest assets on a Shopify store. Compressing them correctly can reduce page weight by **50% to 80%** without losing visible quality.

---

## 1. Best Image Formats for Shopify
*   **WebP (Recommended):** The gold standard for web. It's 25-35% smaller than JPEG but maintains high quality. *Note: Shopify now automatically converts most images to WebP, but uploading optimized files is still best practice.*
*   **JPEG:** Best for product photos and hero banners with many colors.
*   **PNG:** Use **only** when you need transparency. Otherwise, convert to JPEG/WebP.
*   **SVG:** Perfect for logos and icons. They are infinitely scalable and have almost zero file size.

---

## 2. Recommended Compression Tools
Before uploading any image to Shopify, run them through these tools:
1.  **[Squoosh.app](https://squoosh.app/):** (Best overall) Developed by Google. Allows manual control over compression and format conversion.
2.  **[TinyPNG / TinyJPG](https://tinypng.com/):** Great for quick, bulk compression.
3.  **[Adobe Express Resizer](https://www.adobe.com/express/feature/image/resize):** Perfect for resizing images to specific dimensions.

---

## 3. Ideal Dimensions for Shopify
Uploading a 5000px image for a small thumbnail is a common mistake. Follow these standard sizes:

| Placement | Recommended Width | Aspect Ratio |
| :--- | :--- | :--- |
| **Hero Banner (Full Width)** | 1920px - 2560px | 16:9 or 21:9 |
| **Product Images** | 1000px - 1200px | 1:1 (Square) |
| **Blog Post Images** | 900px | 3:2 |
| **Collection Thumbnails** | 600px | 1:1 or 4:5 |
| **Logos** | 200px - 400px | Flexible |

---

## 4. The 5-Step Workflow for High Performance
1.  **Crop:** Remove unnecessary white space around the subject.
2.  **Resize:** Scale the image down to the actual maximum size it will appear on the screen.
3.  **Compress:** Use Squoosh or TinyPNG to bring the file size below **200KB** (for banners) and below **80KB** (for products).
4.  **Rename:** Use SEO-friendly names (e.g., `blue-denim-jacket.jpg` instead of `IMG_5402.jpg`).
5.  **Upload:** Add to Shopify and ensure you provide descriptive **Alt Text**.

---

## 💡 Why "Manual" is better than "App-based" Compression?
Many Shopify apps charge monthly fees to compress images. As an expert, I recommend manual compression because:
- **Zero Ongoing Costs:** No monthly app subscriptions for the client.
- **Better Quality Control:** Apps often over-compress, making images look blurry.
- **No Extra Code:** Apps often add heavy JavaScript to the theme, which can actually slow down the store.
